# Mesa de Partes Digital

## Descripción del proyecto

Mesa de Partes Digital es un sistema desarrollado en Python que permite gestionar expedientes de manera sencilla desde una interfaz de consola. Su finalidad es facilitar el registro, la búsqueda y el seguimiento de documentos.

## Objetivo

Desarrollar una aplicación que permita organizar la información de los expedientes y consultar su estado de manera rápida.

## Funcionalidades

- Registrar nuevos expedientes.
- Buscar expedientes por sus datos, incluido el número de documento.
- Consultar la información registrada.
- Actualizar la información y el estado de los expedientes.
- Guardar los registros localmente mediante archivos JSON.

## Tecnologías utilizadas

- Python
- Archivos JSON
- Git y GitHub para el control de versiones.

## Ejecución del programa

1. Instalar Python.
2. Descargar o clonar este repositorio.
3. Abrir una terminal en la carpeta del proyecto.
4. Ejecutar el siguiente comando:

```bash
python main.py
```

## Estado del proyecto

El sistema se encuentra en desarrollo. Se realizan pruebas de las funciones principales y mejoras progresivas para comprobar su funcionamiento.
